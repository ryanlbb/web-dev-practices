# Descrição

Neste exercício prático, você irá construir a bandeiras da Botswana usando CSS.


O objetivo deste exercício é exercitar o seu conhecimento sobre o CSS Box Model e Flexbox.

**Todas as alterações devem ser feitas nos arquivos já existentes**

* src/index.html -> quando for necessário alterar HTML
* src/css/estilo.css -> quando for necessário alterar CSS
* src/js/script.js -> quando for necessário alterar JavaScript

## Instruções:

1. Construa a bandeira da Botswana alterando o conteúdo do arquivo **src/index.html** e **src/css/estilo.css**
1. Sua bandeira deve ficar parecido com a bandeira abaixo:
